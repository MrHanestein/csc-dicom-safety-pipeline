| **HAZ-09** | Stage 5 (Gate) | De-identified file containing residual PHI is uploaded to Orthanc before validation completes. | Validation run as a passive report rather than a blocking gate. | Leaked patient scan stored in PACS database on port `8042`. | Unauthorized PHI exposure on research server. | 3x3 = 9 (Med) | `run_pipeline_with_audit_log()` executes `stage5_leak_validator_gate()` first and calls `output_path.unlink()` to delete failing files. | 3x1 = 3 (Low) |
| **HAZ-10** | Stage 4 (Header) | File Meta `MediaStorageSOPInstanceUID` (`0002,0003`) holds original un-anonymized UID. | Updating `(0008,0018)` without synchronizing `ds.file_meta`. | Original hospital UID leaked inside DICOM File Meta preamble. | Metadata linkage back to original hospital PACS record. | 3x3 = 9 (Med) | Explicitly synchronizes `ds.file_meta.MediaStorageSOPInstanceUID = ds.SOPInstanceUID`. | 3x1 = 3 (Low) |
| **HAZ-11** | Stage 6 (Audit) | Silent file corruption or bit-rot during de-identification goes undetected. | No cryptographic hash recorded before/after transformation. | Corrupted pixel array ingested into research dataset without traceability. | Invalid model outputs with no forensic audit trail. | 2x3 = 6 (Med) | Streaming SHA-256 checksums (`hashlib.file_digest`) recorded in `audit.jsonl` on every run. | 2x1 = 2 (Low) |
